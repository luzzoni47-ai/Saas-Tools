Answers

Frequently asked questions

Is this Markdown to HTML converter really free?
Yes — completely free, with no account, no watermark and no usage limits. There are no display ads anywhere on the page.
Does it support GitHub Flavored Markdown (GFM)?
Fully. You get pipe tables with column alignment, task lists with [ ] and [x] checkboxes, ~~strikethrough~~, fenced code blocks with syntax highlighting, nested lists, blockquotes and horizontal rules.
Is my content uploaded to a server?
No. The parser runs 100% inside your browser using JavaScript. Nothing is transmitted, logged or stored. You can disconnect from the internet after page load and it will keep working.
How do I export the result as HTML or PDF?
Use the Pro Export Suite in the toolbar: Copy HTML puts the markup on your clipboard, .html downloads a standalone document, .md saves your source, and Export PDF opens your browser's print dialog with a clean print stylesheet.
What does the Smart Clean Engine actually do?
Three optional passes: Strip <script> removes script tags, event handlers and javascript: URLs; Tailwind classes injects utility classes; Minify collapses whitespace outside code blocks.
Which keyboard shortcuts are supported?
Cmd/Ctrl + B bold, Cmd/Ctrl + I italic, Cmd/Ctrl + Shift + C copy HTML instantly, Tab inserts two spaces inside the editor.
