      Frequently asked questions

      Is it safe to type my real password into this checker? ›
      Yes — with one important caveat. This tool runs entirely in your browser using JavaScript. Your password is never transmitted over the network, never logged, and never stored. You can verify this yourself by opening DevTools → Network tab and watching that no request is made while you type. That said, as a general security rule, we recommend testing a near-identical variant of a real password rather than the exact one you use.
      How is password strength actually calculated? ›
      We compute Shannon entropy: the password length multiplied by log₂ of the character pool size (26 for lowercase, 26 for uppercase, 10 for digits, ~33 for symbols). We then apply penalties for common dictionary passwords, repeated characters, alphabet sequences and keyboard walks like "qwerty". The result is expressed in bits — the higher the better. 80+ bits is considered strong against modern offline attacks.
      What does the "time to crack" number mean? ›
      It estimates how long an attacker with a high-end GPU rig performing roughly 10 billion guesses per second would need to exhaust half the possible keyspace. Real-world attacks vary — targeted attacks against a specific person can be far faster — but the figure is a reliable relative measure for comparing passwords against each other.
      How long should my password be in 2025? ›
      For most accounts, 16 characters or more is the sweet spot. Length matters far more than complexity: a 20-character passphrase of random lowercase words is stronger and easier to remember than an 8-character string with symbols. Use 12 characters as an absolute floor, and 20+ for email, banking and password-manager master passwords.
      Are the generated passwords truly random? ›
      Yes. We use the Web Crypto API (crypto.getRandomValues) with rejection sampling to eliminate modulo bias, which produces cryptographically secure randomness — not the predictable Math.random() used by many weaker generators. Nothing about the generated password is sent anywhere or retained after you close the tab.
