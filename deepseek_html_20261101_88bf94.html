Your text never leaves your device. All conversions and counters run locally in your browser using JavaScript — nothing is transmitted to a server, stored in a database or logged. You can even disconnect from the internet after the page loads and the converter will keep working.

Title Case follows editorial style rules: every major word is capitalized, while short articles and prepositions — “a”, “an”, “the”, “of”, “in”, “to”, “and” — stay lowercase unless they're the first or last word. Capitalized Case is simpler: it capitalizes the first letter of every single word, with no exceptions.

These are developer naming conventions. snake_case is common in Python and SQL, kebab-case in URLs, CSS classes and HTML attributes, PascalCase for React components and C# classes, and camelCase for JavaScript variables and JSON keys. The converter intelligently splits existing camelCase, hyphens and underscores before re-joining them in your chosen style.
